## Results

- `test_runs.csv`: recomputed metrics for all 17 submissions; `scope` separates selected and historical runs.
- `test_summary.csv`, `test_paired.csv`: means, sample SDs and within-seed changes. All groups and paired comparisons use seeds **0–2**.
- `test_per_class.csv`: precision, recall, F1 and support for every species in every submitted run.
- `test_species_changes.csv`: synthetic-minus-real per-species F1 changes across matched seeds, separately for 10-/20-shot.
- `test_failure_examples.csv`: three deterministic prediction-based examples; original photos and source hashes are in `failure_images/`, with visual discussion in the [weekly report](../../docs/WEEKLY_REPORT_2026-11-03.md).
- `test_comparison.png`, `test_paired.png`: test figures for all five complete three-seed groups.
- `test_verification.json`: checked counts, manifest hash, complete selected-run coverage and limitations.
- `validation_summary.csv`, `validation_paired.csv` and matching `validation_*.png`: separate validation results.
- `training_runtime.csv`: observed training times and hardware/software for all 15 runs. Generation cost is separate in [generation_records.md](../generation/generation_records.md).
- `checkpoint_inventory.json`: SHA-256 and metadata for all 15 selected local checkpoints; this does not claim inference replay.

Scores in CSVs are fractions; differences ending in `_pp` are percentage points. Error bars show sample SD across available seeds, not confidence intervals.

## Source and verification

Archives: `best_checkpoints_test.zip` and `best_checkpoints_test_safina.rar`. [Import provenance](../test/import_provenance.json) records their hashes, original directories, checkpoint identity and CSV hashes. Duplicate synthetic 10-shot submissions match byte-for-byte.

Predictions are stored losslessly as `reports/test/<run>/test_predictions.csv.gz` to avoid adding roughly 100,000 raw CSV lines to Git. Original uncompressed CSVs and weights remain under ignored `outputs/`; some checkpoint paths reuse pre-existing identical files. Open compressed files with Python's `gzip` or an archive utility.

Every CSV is checked against the exact test-manifest IDs, labels, row order and species mapping. Metrics are recomputed from hard labels with all 200 species and zero F1 when a species is never predicted. Checkpoint configs and selected steps match corresponding saved validation results. Historical diagnostics are not substituted into the selected comparison.

The archives contain **no original evaluation_config.json or test metric JSONs**. Reconstruction supplies metrics but cannot recover loss, confidence, inference hardware/software or independent evidence that each CSV was generated by its co-delivered checkpoint. No test inference was rerun locally. These limitations remain explicit in the report.

## Reproduce

From the repository root, with matplotlib; torch is needed for checkpoint checks/import, libarchive-c for RAR import:

```bash
python src/check_reproducibility.py --require-complete
python src/report_comparison.py --checkpoints
python src/report_test_results.py
```

To repeat the archive import, preserving original bytes and refusing conflicting data:

```bash
python src/import_test_archives.py /path/to/best_checkpoints_test.zip /path/to/best_checkpoints_test_safina.rar
```

The dated 27 October comparison remains a snapshot of the 12 runs available then.
